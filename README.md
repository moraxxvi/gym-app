# Зал для новичка

Бесплатный помощник для тех, кто начинает ходить в зал (или возвращается). На русском.

**Открыть:** https://moraxxvi.github.io/gym-app/ — на телефоне «Добавить на главный экран».

## Что умеет
- Анкета → план: 10 схем на 2–6 тренировок в неделю (включая акцент на ноги и ягодицы)
- Свои программы: конструктор дней, упражнений, подходов и повторов; можно добавить своё упражнение
- Режим тренировки: подход за подходом, таймер отдыха, подсказка, когда добавлять вес
- 53 упражнения: фото, карта мышц, техника, частые ошибки, замены
- Прогресс: календарь, серия недель, график по каждому упражнению
- Гайды для новичка
- Работает без интернета, данные хранятся только в телефоне

Фото упражнений: [Free Exercise DB](https://github.com/yuhonas/free-exercise-db) (public domain).
